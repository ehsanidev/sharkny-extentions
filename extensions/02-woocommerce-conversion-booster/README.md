# WooCommerce Conversion Booster

Starter plugin folder for WordPress extension development.

## Purpose
Enhance store conversion using urgency prompts, cart behavior analytics, and recommendation widgets.

## Suggested files
- `woocommerce-conversion-booster.php`
- `includes/cart-hooks.php`
- `includes/analytics.php`
- `assets/admin.js`

## Notes
This folder is a starter template for one of the planned marketplace extensions.

# Booking & Reservations

Starter plugin folder for WordPress extension development.

## Purpose
Manage appointments, bookings, and service scheduling from the WordPress admin panel.

## Suggested files
- `booking-reservations.php`
- `includes/calendar.php`
- `includes/booking-controller.php`
- `templates/booking-form.php`

## Notes
This folder is a starter template for one of the planned marketplace extensions.

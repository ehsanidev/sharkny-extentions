# Multilingual Content Pack

Starter plugin folder for WordPress extension development.

## Purpose
Add multilingual content controls, translation tools, and locale switching for WordPress sites.

## Suggested files
- `multilingual-content-pack.php`
- `includes/translation-sync.php`
- `includes/locale-switcher.php`
- `assets/language-menu.js`

## Notes
This folder is a starter template for one of the planned marketplace extensions.
